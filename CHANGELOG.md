# Changelog

## 0.1.0

The first public release. It targets Apple silicon macOS 14 or later, with English as the supported interface language.
It includes local media import, reference-led creation, editable timelines and video export; runtimes and
models install through the component manager. Users can connect their own AI accounts. No Taalcut premium
plan, managed service or bundled AI credit sale is enabled.

It ships as a drag-to-Applications disk image, signed with a Developer ID and notarized by Apple, with
dependency security updates, third-party notices, separate terms for the demonstration footage and a
translation contribution path. See the [release notes](release-notes/0.1.0/en.md).
