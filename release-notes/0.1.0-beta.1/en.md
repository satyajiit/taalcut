**Taalcut 0.1.0-beta.1**

- First macOS beta for Apple silicon on macOS 14 or later.
- Import your footage, use a reference reel to guide an edit, review the timeline and export a video.
- On-device models and runtimes install through Taalcut. Connect your own AI account when using a cloud provider; provider charges are separate.
- Install by dragging Taalcut into Applications from the signed macOS disk image.
- English is the supported interface language. Hindi, Spanish and Brazilian Portuguese are draft translations open to contributors.
- Premium plans and managed AI credits are not available in this beta.
- This is pre-release software. Keep your original media and review an export before publishing it.
