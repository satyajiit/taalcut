Third-party licence texts for the bundled FFmpeg build (linux-x64)

These are the licence texts of the code statically linked into the seven FFmpeg shared libraries
(lib/*.so.*) that tools/ffmpeg/build-linux.sh builds from the pins in tools/ffmpeg/versions.env, in the
pinned Ubuntu 22.04 toolchain image (linux-x64.Dockerfile). The binaries' BUILDINFO.json lists every source
with its URL and SHA-256; tools/ffmpeg/SOURCE.md is the source offer.

FFmpeg 9.0.2 itself is LGPL-2.1-or-later (--disable-gpl --disable-nonfree --disable-version3); its text
ships as dist/linux-x64/LICENSE.txt (FFmpeg's COPYING.LGPLv2.1) and is not repeated here.

Line format: name | upstream | pinned version | SPDX licence expression | files
Files are named <Library>-<OriginalFileName> and hold the upstream bytes unchanged, except the
nv-codec-headers notices, which are verbatim excerpts of the header comments (the tarball has no licence
file). "+ ..." in the SPDX field marks a patent licence that sits beside the copyright licence.
build-linux.sh copies the texts from the trees it builds and stops if a file here is from no library it
links, or if this index doesn't name one.

# B. Used to build, not in the binaries
Vulkan-Loader vulkan-sdk-1.4.357.0 (linked against; the system's libvulkan.so.1 is loaded at run time),
jinja2 3.1.6 and MarkupSafe 3.0.3 (libplacebo's code generator), CMake 3.31.12, Meson 1.12.1, and the
image's Ubuntu packages (gcc, clang-14 for the CUDA kernels, nasm, binutils; BUILDINFO.json's toolchain).

# C. From the system at run time, not shipped
glibc (libc6 2.35 or later), the Vulkan loader (libvulkan1, Apache-2.0), libva and libva-drm 2.x (MIT,
with libdrm, MIT) for VA-API, and the NVIDIA driver's libcuda, libnvcuvid and libnvidia-encode, which
FFmpeg opens at run time when NVDEC, NVENC or CUDA filters are used (NVIDIA's driver licence).
