# Spanish glossary (draft, for the native review H8)

The words the draft catalogues use for Taalcut's terms. A reviewer who changes a term changes it here and in every string that uses it (`pnpm i18n:handoff es --out <dir>` copies this file into the hand-off).

## Register

Neutral Latin American Spanish, tú. "video" without an accent, "agregar" (not añadir). Buttons and menu items in the infinitive (Exportar, Agregar carpeta); instructions in the tú imperative (Elige una carpeta). Sentence case; ¿ ¡ always.

## Plurals

`one`, `many` and `other`, all three, always; `many` (exact millions) repeats `other`.
