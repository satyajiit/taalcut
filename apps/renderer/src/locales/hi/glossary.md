# Hindi glossary (draft, for the native review H8)

The words the draft catalogues use for Taalcut's terms. A reviewer who changes a term changes it here and in every string that uses it (`pnpm i18n:handoff hi --out <dir>` copies this file into the hand-off).

## Register

आप, with polite imperatives (करें, चुनें, जोड़ें). Everyday Hindustani as YouTube's and Instagram's Hindi UIs speak it, not Sanskritised Hindi: इस्तेमाल, सेटिंग्स, फ़ाइल. Common tech loanwords in Devanagari (क्लिप, वीडियो, टेम्पलेट); product names in Latin letters (Taalcut, Mac, iPhone, ChatGPT, Wi-Fi). Nukta forms throughout (फ़, ज़, ख़). Sentences end with ।. Text the person reads aloud or that speaks as them avoids gendered first-person verbs.

## Plurals

`one` and `other`; `one` is 0 and 1, so the drafts add `=0 {…}` where the singular reads wrong for zero.
