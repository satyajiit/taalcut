# Brazilian Portuguese glossary (draft, for the native review H8)

The words the draft catalogues use for Taalcut's terms. A reviewer who changes a term changes it here and in every string that uses it (`pnpm i18n:handoff pt-BR --out <dir>` copies this file into the hand-off).

## Register

Brazilian Portuguese, você. Buttons and menu items in the infinitive (Exportar, Baixar); instructions in the imperative (Escolha uma pasta). "vídeo", "arquivo", "pasta", "celular", "baixar". Sentence case, except macOS's own menu items, which keep Apple's capitalisation.

## Plurals

`one`, `many` and `other`, all three, always; `one` is 0 and 1, so the drafts add `=0 {…}` where the singular reads wrong for zero; `many` repeats `other`.
