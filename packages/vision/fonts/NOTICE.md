# Bundled fonts for vision font match

Unmodified Regular files, SPDX `OFL-1.1`. Outlines were not changed, so a Reserved Font Name stays with the upstream name. These files stay OFL inside the AGPL app; documents rendered with them are not OFL.

Families that are variable-only on `google/fonts` `main` are the last static Regular that repo published, or the official upstream static file. No family was substituted.
